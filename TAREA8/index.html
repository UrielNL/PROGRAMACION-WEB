Tipos de estilos css

Estilos de linea

Estos estilos se van a agregar directamente directamente en elemento html mediante el atributo style

este parrafo tiene estilos en linea

Estilos internos

Estos estilos se agregan en el mismo archivo html dentro de la etiqueta <head > y para agregarlos se utliza el elemento <style >

Estilos externos

Estos estilos son los que se recomienda utilizar ya que ofece regularidad , y facil mantenimiento , orden , eficiencia , entre otras ventajas, para agregar una hoja de estilos externa , dentro de la etiqueta <style> se utliza el elemento <link> , donde se especifico la ruta de nuestra hoja de estilos.
